# Hitos del proyecto

Memoria de qué se ha hecho en este sitio y **por qué**. Se lee de arriba hacia
abajo para ponerse al día rápido: lo más reciente primero.

- `CLAUDE.md` → cómo se trabaja **hoy** (estado actual, reglas, convenciones).
- `.claude/hitos/` → cómo se llegó hasta aquí (historia y decisiones).
- `.claude/skills/` → procedimientos repetibles paso a paso.
- `briefing.md` → qué pidió el cliente y qué quedó fuera de alcance.

No se duplica información entre ellos. Para añadir un hito, ver la skill
`registrar-hito`.

> Si un hito descubre un defecto de la **plantilla** (algo que le pasaría
> igual al siguiente sitio), el arreglo de aquí es hito de este proyecto, y la
> corrección de la plantilla es hito de `../WebMaker/hitos/`. Sin las dos
> anotaciones, el siguiente proyecto repite el error.
